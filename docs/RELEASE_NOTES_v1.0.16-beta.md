## 本版重点

### 1. 会话目录隔离

- 每个会话默认使用独立目录：`/storage/emulated/0/PhoneAgent/<32位hex>/`
- 目录 key 取 `SHA-256(conversationId)` 前 16 字节，同一会话重启后仍对应原目录
- 上传附件、AI 产物默认落到当前会话目录，不再全部堆进公共工作区
- `shell_exec` 默认工作目录切到当前会话目录
- 命名工作区继续作为跨会话共享项目保留，自由模式仍可在设置中选择

> 旧会话的附件仍在原 `filesDir/attachments`，没有自动迁移；旧附件路径默认会被当前工作区沙箱拒绝。

### 2. 流式输出完整显示

- 流结束、工具切换、异常收尾都强制 flush，最后一段文字不再丢失
- 工具调用前不再立刻清空气泡，过程文字先落库并挂进消息列表，再进入下一步
- 旧文字等新一步第一个增量到达后再清理，避免闪烁
- 停止生成时使用完整 `streamBuf` 落库，而不是上一帧的 `streamingText`
- 最终回答增加 Room Flow 慢时的直接查库兜底；思维链不再截断到 240 字

### 3. 完成提示与跟随滚动

- 模型思考或输出时，用户上滑可以停止自动跟随，安心查看旧内容
- 只有正常完整回答结束且用户不在底部时，才显示「回答已完成 ↓」
- 用户手动回到底部或点击按钮后，提示消失
- 报错、超时、用户主动停止不会触发完成提示
- 区分用户滚动与程序滚动，避免自动跟随把用户拉回底部

### 4. 工具失败不再进运行日志

- `web_fetch` 连接失败、`ping` 返回 `ERROR(1)` 等正常工具错误不再写入「设置 → 运行日志」
- 工具失败仍保留为聊天里的 error 执行步骤，也会回传给模型重试
- 历史日志不会自动删除，需要手动点「清空」

### 5. Token 优化

- 常规对话默认只带 36 个核心工具，不再每次固定塞 66 个工具定义
- 命中「安装 / 卸载 / APK / 启动 / 截图 / 点击 / 系统设置 / 内存 / 磁盘 / ping」等关键词时，再追加对应工具分组
- 用户自定义工具始终保留；正文直接点名工具也强制保留
- 系统提示删掉与工具清单重复的「能力范围」大段，从 6330 字压到 4260 字

### 6. 更新弹窗优化

- 首页只显示最多 4 条「本版重点」，不再先展示版本号、SHA、APK 大小和安装说明
- 自动过滤 `versionCode`、`minSdk`、`APK 约`、`SHA-256`、覆盖安装、下载地址、免责声明等噪声
- 首页不再出现 `#`、`**`、反引号、链接语法等 Markdown 符号
- 详情页按标题、列表、代码块结构化排版，列表统一为 `•`
- 详情页支持滚动与长按复制
- 自动检查更新弹窗和设置页手动检查更新弹窗都已接入

## 1.0.16-beta 完整变更

- 新增 `ConversationWorkspace`：按会话 ID 生成独立目录，统一附件和产物落点

- 新增 `ToolSelector`：核心工具常驻，应用 / 屏幕 / 系统 / 网络诊断按关键词追加
- 新增 `ReleaseNotes`：更新说明重点提取与详情 Markdown 清理
- 新增目录命名、工具选择、更新说明三组单元测试
- 修复流式输出最后一段丢失、工具切换清空气泡、停止生成内容不完整
- 修复完成提示误弹、自动跟随抢滚动、用户上滑被拉回底部
- 移除工具失败写 `AppLog`，运行日志不再被正常工具错误刷屏
- 压缩系统提示，减少重复的工具能力描述

## 安装与升级

1. 下载本 Release 的 APK，直接安装（首次需允许「安装未知来源」）
2. 已安装 1.0.15 或更早公开版可直接覆盖，签名保持一致，应用数据保留
3. 打开后按引导完成文件访问权限、Shizuku / Root 授权与模型配置

这是 beta 包，版本名固定为 `1.0.16-beta`，构建号 `89`。如果之前装的是自行改签名的包，覆盖安装可能失败；先卸载旧版再装，卸载会清除应用数据。

## 已知限制

- 旧消息附件没有迁移到新的会话目录，旧附件路径可能被沙箱拒绝
- 删除会话只删除数据库记录，不会自动删除 `PhoneAgent/<hash>/` 下的文件
- `shell_exec` 仍可用显式绝对路径访问工作区外，当前靠提示词约束，不是硬沙箱
- Token 优化后的真实模型请求量和工具覆盖仍需真机验收
- 更新弹窗首页重点条数与详情字号仍需真机视觉验收
- 旧版 `.doc` / `.ppt` 生成仍需要 LibreOffice 等转换器
- PDF 暂无内置渲染
