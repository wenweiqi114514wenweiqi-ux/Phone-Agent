## 本版重点

### 1. 旧附件自动迁移

- 首次启动扫描旧消息里的附件记录，只处理来源位于 `filesDir/attachments` 或 `cacheDir/attachments` 的文件
- 复制到该消息所属会话的 `PhoneAgent/<hash>/` 目录，重名自动追加序号，不覆盖已有文件
- 同步更新消息里的附件路径与大小；原文件保留，不删除旧数据
- 迁移结果记录在 `phone_agent_attachment_migration`，并写入启动日志的 copied / updated / missing / failed 计数
- 迁移失败只记录日志，不阻塞启动

### 2. 删除会话时清理文件

- 会话列表与已归档页共用同一个删除弹窗，行为一致
- 弹窗显示该会话目录占用大小，并提供「同时删除本会话文件」复选框，默认勾选
- 确认后先删 `PhoneAgent/<hash>/`，再删消息与会话记录；取消勾选则保留目录
- 删除当前会话后自动切回默认会话

### 3. 会话存储管理

- 设置页新增「会话文件」卡片，显示全部会话目录总占用
- 「清理无主会话目录」会读取全部会话 ID（含归档，并额外保留 `default`），删除没有对应会话记录的目录
- 清理完成后显示清理目录数量与释放空间

### 4. 工具选择器口语同义词

- 补充「截屏 / 点一下 / 划一下 / 按一下 / 装一下 / 存储空间 / 系统版本 / 后台运行」等口语说法
- 这些说法会命中对应的屏幕操作、应用管理、系统信息工具组，不再依赖书面关键词

### 5. 保留 1.0.16-beta 的全部改进

- 每个会话独立目录，附件、AI 产物与 `shell_exec` 默认 CWD 跟随当前会话
- 流式输出收尾兜底，最后一段不丢失；消息先落库再进入下一步
- 完成提示与跟随滚动：用户上滑停止跟随，只有正常完成且不在底部时才提示「回答已完成 ↓」
- 工具失败不再写入运行日志，聊天里仍保留 error 步骤
- 常规对话只下发 36 个核心工具，按关键词追加工具组
- 更新弹窗首页只保留本版重点，详情页清除 Markdown 符号并结构化排版

## 安装与升级

1. 下载本 Release 的 APK，直接安装（首次需允许「安装未知来源」）
2. 已安装 1.0.15、1.0.16-beta 或更早公开版可直接覆盖，签名保持一致，应用数据保留
3. 打开后按引导完成文件访问权限、Shizuku / Root 授权与模型配置

正式版与 beta 共用包名 `com.phoneagent`，无法同时安装；系统仅允许升级到更高 versionCode。

## 已知限制

- 旧附件迁移只扫描 `filesDir/attachments` 与 `cacheDir/attachments`；用户放在其他自定义路径的旧附件不会自动搬进会话目录
- 删除会话默认勾选「同时删除本会话文件」；取消勾选会保留目录，之后可在设置页作为无主目录清理
- `shell_exec` 仍可通过显式绝对路径访问工作区外，路径约束靠提示词和文件工具沙箱，不是硬沙箱
- 旧版 `.doc` / `.ppt` 生成仍需要 LibreOffice 等转换器
- PDF 暂无内置渲染；音视频使用应用内播放器打开
