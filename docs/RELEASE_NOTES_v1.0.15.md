# v1.0.15 · 正式版

> versionCode 83 · minSdk 26（Android 8.0）· targetSdk 36
> APK 约 80 MB · SHA-256 `1f52e9933691f3efe0cfb99d615a8535f59087a3aa804f25aa9be0b7899a87bc`
> 覆盖安装保留会话、模型配置、工作区、记忆与设置

1.0.15 从 beta 收束为正式版。这一版的重点不在堆功能，而是把手机端最常用的三件事补齐：打开表格、打开 Word、每天找会话。

---

## 本版重点

### 1. 测试组件：内置离线 Python 3.14

- 设置新增「测试性功能 → Python 组件」，与「权限与执行」分开
- 内置 `Python 3.14.10`（arm64-v8a），随 APK 打包，不联网下载、不拉取依赖
- 首次打开测试组件页，或模型第一次执行 `python3` 时自动准备
- 安装到 `/data/local/tmp/phoneagent`，避开 Android 10+ 不能执行应用私有目录二进制的限制
- 自动完成解压、复制、权限设置、自检、全局 wrapper 与卸载
- 注入 `PATH`、`HOME`、`TMPDIR`、`PYTHONHOME`、`SSL_CERT_FILE` 等运行环境
- 实机验证：Python `3.14.10`、OpenSSL `3.6.5`、SQLite `3.54.1`、UTF-8 中文与 WAV 生成均正常

> 当前只提供 Python 一个白名单组件；FFmpeg 尚未加入，也不会在运行时联网安装杂项组件。

### 2. 表格预览统一

- `.csv`、`.xls`、`.xlsx`、`.ods` 全部走同一个表格页，不再出现 CSV 被当纯文本显示逗号原文
- CSV 优先 UTF-8 严格解码，失败回退 GB18030，处理 BOM、空单元格、带逗号字段与双引号转义
- XLS / XLSX / ODS 支持多工作表页签、合并单元格
- 只渲染 `!ref` 实际内容范围，不再无限向下延伸空白行
- 顶部统一显示文件名、`Universal File Preview · MIT` 与 `N 行 · M 列`
- 超过 2000 行 / 100 列时截断并提示，超宽可左右滑动

### 3. DOCX 手机端自适应

- 窄屏不再按 A4 固定宽度渲染，纸面宽度改为 100%
- 缩小左右内边距、去掉固定最小高度与阴影，正文不再被挤成多行
- 桌面宽屏仍保留原来的纸面观感

### 4. 会话页重做

- 去掉嵌套 Scaffold 与悬浮 FAB，页头改为「全部会话 + 会话数 / 消息数 + 新建」
- 增加本地标题搜索，支持清除与键盘搜索
- 按「今天 / 昨天 / M月d日 / yyyy年M月d日」分组，组头带数量与分隔线
- 卡片统一为 `Surface`：圆形字母头像、当前会话高亮边框与「当前」标记、时间、消息数、最后一条消息预览
- 右上角更多菜单保留重命名、归档、删除
- 空状态与搜索无结果状态单独设计

## 安装与升级

1. 下载本 Release 的 APK，直接安装（首次需允许「安装未知来源」）
2. 已安装旧版可直接覆盖，签名与 1.0.13 起的公开版本一致，数据保留
3. 打开后按引导完成 Shizuku / Root 授权、文件访问权限与模型配置

如果之前装的是测试版或自行改签名的包，覆盖安装可能失败；先卸载旧版再装，卸载会清除应用数据。

## 已知限制

- 旧版 `.doc` / `.ppt` 的生成仍需要 LibreOffice 等转换器，内置 Python 组件不解决
- 统一表格预览以内容和结构为主，不保留复杂单元格底色、特殊字体和图表
- PDF 暂无内置渲染
- 测试组件目前只有 Python 3.14（arm64），FFmpeg 尚未提供
- 不做无障碍 UI 自动化，无法逐屏点按第三方 App 界面
