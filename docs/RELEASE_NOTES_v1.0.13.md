# v1.0.13 · 首个公开版本

> versionCode 61 · minSdk 26（Android 8.0）· targetSdk 36
> APK 体积约 54 MB（debug 构建，未压缩资源）

把手机当成一台可以被 AI 直接操作的小电脑：说一句话，它自己动手改文件、跑脚本、操作工作区，改完把文件卡片交回聊天里，点开就能在应用内预览。

---

## 核心能力

### 对话与模型
- 任意 **OpenAI 兼容接口**（DeepSeek / 豆包 / 通义 / 自建 / Ollama），支持多套模型配置并存与一键切换
- 深度思考模式（reasoning 内容不参与多轮上下文，避免跨轮"套用思考"）
- 会话持久化、自动命名、归档；覆盖升级不丢数据

### Agent 执行
- 多步工具循环：模型可连续调用工具，过程折叠成「已执行 N 条命令」，可展开看每步命令与输出
- 执行通道：**Shizuku 优先**（免 root，一次 adb 授权长期可用），失败回退 Root
- 三档安全策略（全部允许 / 需要确认 / 全部拒绝），高危命令弹窗确认
- 连续相同调用会被拦下，防止模型复读空转

### 工作区沙箱
- 可指定任意目录为工作区，AI 只能在此读写
- 相对路径按**工作区根**解析（不是进程 CWD），`file_copy` / `file_move` 的源与目标双路径校验
- 只读工作区会直接拦下写操作；越界时给出明确提示（工作区绝对路径 + 该怎么填）

### 文件交付（不复制）
- AI 改过的文件**只记录真实路径、不复制副本**，不占额外空间
- 一轮里改过文件但模型没主动提交 → 应用侧兜底自动生成提交卡
- 同一会话同一路径天然去重，版本号 `vN` 递增
- 卡片显示：类型图标、`大小 · 类型 · 已提交 v2 / 已修改`、时间；文件被删显示「已不存在」
- 多文件折叠（>3 显示"还有 N 个"），长按菜单可「用其他应用打开 / 复制路径」

### 内置预览器
- 文本 / Markdown / HTML / 图片（双指缩放、双击复位）
- 文本：分块渲染（长文件秒开）、自动换行开关、字号 A-/A+、长按可选中复制
- 每页右上角文件信息面板与「用其他应用打开」

### 流式输出
- 正文逐字增长，约 60ms 刷新一次，末尾呼吸光标
- **代码从第一行起就进代码框**，随行数向下延伸；未闭合的 ``` 与未配对的 `**` 不会露出来
- 支持**停止生成**（连接即时切断），已生成内容保留并标注「（已停止）」
- 工具执行期间气泡不消失；流式与最终渲染同构，结束时不会整块跳变

### 消息操作
- 用户消息：`复制`、`重新输入`（✏️，回填输入框并截断其后的对话）
- AI 回答：`重新思考`（↻，删掉该回答后用同一问题重跑）
- AI 正文与代码块长按可选中，调系统文字工具栏

### 输入体验
- 回车即发送；最多长到 6 行
- 草稿按会话保留，切会话 / 切页 / 旋转都不丢
- 发送失败自动回填原文
- 生成中仍可继续输入，再发一条会**排队**，本轮结束自动发出

### 权限与稳定性
- **启动即检测文件访问权限**：缺权限当场弹窗，去系统开启返回后自动消失；设置页显示「已开启 / 未开启」状态；打开预览前再兜底检测
- 兼容 Android 10 及以下的运行时读写权限分支
- 运行日志分级：软件问题（WARN/ERROR）与环境权限类问题（ENV）分开统计，设置里可查看/复制/清空
- 崩溃回执页 + 数据库自愈（迁移 schema 逐表逐列幂等对齐，损坏库自动备份后恢复，绝不改名用户库）

## 安装

1. 下载本 Release 的 `app-debug.apk`，直接安装（首次需允许"安装未知来源"）
2. 打开后按引导完成两件事：
   - **Shizuku 授权**：装 Shizuku，用 adb 启动一次服务，在应用内授权（免 root 拿执行能力）
   - **文件访问权限**：工作区在 `/storage/emulated/0` 下时，需要「所有文件访问权限」才能预览文件
3. 进入「设置 → 模型与接入」，添加一个模型并填入 API Key

> 覆盖安装会保留全部数据（会话、模型配置、工作区、记忆）。

## 已知限制

- Office（docx / xlsx / pptx）与音视频暂不支持内置预览，会给出「用其他应用打开」入口
- 流式阶段表格仍按文本显示，闭合后才成表（会有一处排版变化）
- 需要 Shizuku 或 Root 才能执行系统级命令；纯聊天与文件预览不需要
